# MESS FOOD WASTAGE PREDICTION
A Google-powered system prototype that predicts daily mess attendance to reduce food wastage and improve campus sustainability.

## Problem
In college messes, a large amount of food is wasted daily due to inaccurate estimation of student turnout.

## Solution
This prototype predicts daily mess attendance using past data and day-based factors such as weekends, holidays and meal prepared.  
Based on the prediction, it recommends how much food should be prepared to reduce wastage.

## Google Technologies used
- Google Sheets – Data collection and storage.
- Google Fonts – UI design and consistency.
- Gemini API – AI-powered advisory insights.

## How It Works
1. Upload CSV – Load historical mess attendance and waste data.
2. Select Factors – Choose day, festival, academic status, menu.
3. Analyze Data – Calculate averages and identify high-waste dishes.
4. Predict Attendance – Estimate student turnout using historical patterns.
5. Display Results – Show count, warnings, and pie chart.
6. AI Advice – Get portion control tips via Google Gemini AI.

## Impact
- Reduces food wastage
- Saves cost
- Improves campus sustainability
